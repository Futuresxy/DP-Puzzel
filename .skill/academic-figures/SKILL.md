# 论文绘图

以目标模板的成稿尺寸设计插图。先确认图要支持的比较或展示的机制，再选择坐标、编码和版式。复用现有绘图入口、实验数据和论文术语。处理作者提供的架构图时，以作者的可编辑图稿为源，沿用项目对架构图制作的约定。[论文入口和排版](../../paper/README.md) · [投稿要求](../../paper/submission/requirements.md)

## 图内文字与 LaTeX 图注

- 图中文字统一使用英文，包括中文稿中的图。保留量名、单位、主要刻度、短图例和机制所需的模块、阶段、信号标签。数字、缩写、数学符号和 SI 单位照常使用。标签用短词组并与论文和规格统一，例如 `Total power (mW)`、`Area (µm²)`、`H:Q:E`、`MXFP8 E4M3`。
- 图名、结论、设计解释、读图说明、基准定义、测量工况和补充注释放在 LaTeX 的 `\caption` 或正文。按实际需要保留少量关键数值标签，优先保留基准和读者必须直接读取的值。把配比、精度、颜色和符号的含义写在图注。
- 多面板允许在合图中标 `(a)`、`(b)`，位置与字号保持一致。独立面板由 LaTeX `\subfloat` 编排时，交给 LaTeX 生成面板编号。每个面板只显示一次编号。主图用 `\caption` 和 `\label` 编号及交叉引用，按模板把图注放在图下。

## 版面、字体和视觉编码

- 按实际 `\columnwidth` 或已确定的跨栏宽度出图。单栏优先。并排比较可共用分类轴和图例，重排行列或分面后再决定宽度。在成稿尺寸看刻度、线宽、图例和面板标签，保留足够的间距。[IEEE 图幅与分辨率指南](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/create-graphics-for-your-article/resolution-and-size/)
- 本项目 IEEEtran 图默认使用 Times New Roman。Matplotlib 环境缺少该字体时，依次使用 Liberation Serif、STIXGeneral，并核对实际嵌入的字体。目标模板指定字体时按模板。成稿尺寸优先使用约 9–10 pt，紧凑图的刻度和图例可用 8 pt，并按成稿检查可读性。相同角色的标签在各图保持字号和字重一致。[IEEE 字体与文件格式指南](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/create-graphics-for-your-article/file-formatting/)
- 对同一精度、机制或数据类别保持颜色与符号语义一致。关键分组同时用线型、点形、填充纹理或位置区分，检查灰度下仍可辨认。使用简洁背景和弱网格，视觉重点留给数据与关键路径。[IEEE 图形可读性指南](https://journals.ieeeauthorcenter.ieee.org/create-your-ieee-journal-article/create-graphics-for-your-article/)

## 按图型选择表达

- **面积、功耗与性能。** 以柱状图比较离散配比或精度，柱长从零起算。可直接比较的面板采用一致的单位、刻度与组序。对数轴在坐标和图注中明确说明。标明总功耗、动态功耗、面积与能耗各自的量和单位。归一化时在图注说明分母以及功耗按同精度比较还是共用分母，沿用该比较已确认的口径。
- **实测、模型与不确定性。** 从经核验的输入读数，保留原始精度参与计算，显示时再舍入。用空缺或符号表示未测、不支持或不可比的数据，并在图注解释。按证据区分实测、模型估计和代理值，注明比较工况与测量边界。仅在有样本或明确不确定性依据时画误差条，并解释其含义。
- **机制、流水与数据流。** 选定主要阅读方向，使用规格中的模块名、阶段编号、输入输出名和数据位宽。箭头体现真实传递关系，数据、控制和广播等需要区分时统一线型并在图注解释。图内以块、箭头和短标签呈现结构，原理、条件和步骤解释交给 LaTeX。核对图示与相应规格或实现的版本一致。

## 导出与交付前核对

1. 数据图和机制线图直接输出裁边后的单页矢量 PDF 到 `paper/figures/`。保留绘图脚本或可编辑矢量源。作者提供的位图素材按目标尺寸检查原始分辨率，PNG 可用作预览。
2. Matplotlib 可在创建画布前使用 `plt.style.context(...)` 载入随附样式，并按图指定宽高。样式启用 PDF 字体嵌入。优先保留可选取的文字。矢量编辑器可在需要时将文字转为路径，同时保留可编辑源。[Matplotlib 绘图样式](assets/paper.mplstyle)
3. 用 `pdfinfo` 检查页数和实际图幅，用 `pdffonts` 确认保留为文字的字体已嵌入。用 `pdfimages -list` 检查纯数据图和线图的矢量输出，确保嵌入的位图有明确来源。用 `pdftotext` 核对可提取文字，并渲染预览检查转路径文字、中文残留、裁切和重叠。
4. 将图中单位、数值、归一化分母和类别逐项对回数据或规格。在现有绘图文档记录生成命令和可追溯的输入。已纳入正文的图在论文 PDF 中复核实际尺寸、图注、子图编号和引用。
