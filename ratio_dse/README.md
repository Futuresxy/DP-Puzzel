# ratio_dse：芯片级成本收益权衡

目标：将多精度资源配比和物理实现映射到 **area、power、gemm_compute_latency**，分析 Pareto 前沿、预算可行性以及相对基线的收益。

模型对象是含多个 SM/AICore 类核心的 AI 芯片。每核心有一个或多个计算阵列，以及按配置定义的 L1/L0；芯片共享 HBM 带宽和其他公共资源。具体层级共享关系由 chip config 定义，不预先固定为每阵列一个 L0。

输入包括单阵列/单核硬件 profile、数值格式、芯片拓扑、负载与精度可行性、HBM/存储参数、设计空间和预算。输出包括候选状态、面积分解、真实负载平均/峰值功耗、GEMM 完成延迟、利用率与瓶颈，以及支持结论的来源。

核心职责按 [src/README.md](src/README.md) 划分。详细模型边界见 [架构](../docs/architecture.md)，比较口径见 [实验定义](../docs/experiments.md)。

当前没有模型代码。尚未实现的缓存、并发、转换、功耗和芯片开销不能被写成已支持；缺失证据应明确影响候选的可行性与结果置信程度。
