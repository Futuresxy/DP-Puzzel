# DP-Puzzle 全文故事线与章节组织

版本：讨论与实施提纲 v0.1；日期：2026-11-12（Asia/Shanghai）。本文组织拟开展的研究，不宣称九种配比及软件模型已经全部验收；正文结果以对应回执为准。

## 研究主线

DP-Puzzle 研究芯片多精度算力配置与模型 GEMM 执行精度之间的匹配关系。低精度通路增配改变单元面积、模式功耗和输入需求，并通过核心部署数量影响芯片的分精度绝对算力。模型精度迁移改变各类算力的需求，也可能引入质量损失及转换开销。因此，硬件配比和模型精度应在明确的资源与质量条件下评价。

研究链为：可组合 DP 的电路成本 → 面积/供数约束下的核心部署 → DeepSeek Attention/MoE 的逐算子 GEMM → 精度相关利用率与多核执行 → 双向配比/精度选择。

固定硬件时，搜索允许迁移的算子及目标精度；固定模型与精度方案时，搜索硬件配比及合法阵列配置。两个视角共享底层输入和评价器。质量损失参数、证据接口与约束先设计，具体困惑度/准确率预测及目标模型量化评价后续接入。

## 三项研究内容

1. **具有电路成本依据的配比设计空间。** 以共享多精度、Q、E、QE 模块构成九种配比，量化算力增配的面积和逐模式功耗，并解释资源复用的作用。九种配比以总索引为准，最终两种为 1:6:12、1:8:16。
2. **贯通 DP 与 GEMM 的系统模型。** 将硬件成本转换为统一面积预算下的完整核心数量和绝对算力；结合矩阵形状、精度相关原生 K、边界填充及供数条件，计算利用率和服务时间。
3. **模型与芯片两个视角的 DSE。** 分别分析精度迁移和硬件配置的收益与适用范围；用可配置质量预算约束迁移候选。质量建模未完成时，仅报告条件性的硬件收益，不声称完成质量保持的自动量化。

## 负载范围与叙述层次

只内置 DeepSeek V4/V4.1 的主要 Attention 和 MoE GEMM adapter。四类解释维度为 `attention_core`、`attention_projection`、`shared_or_dense_ffn`、`routed_expert`；Indexer 是 Attention 内的独立子类，保留 Full/Candidate 区别。其他小型 GEMM 进入剩余项账本，不能混进四类后隐去差异。

V4.1 目标执行映射采用用户指定的 BF16 主 QK/PV、Grouped O-down、Global-KV projection；FP8 Q-down/up/O-up、SWA-KV projection、共享专家及 Index Q projection；路由专家 W4A8；Full Indexer QK FP4。该映射是目标 profile，具体编码、参考实现差异和 W4A8 执行路径由任务 B 明确记录。V4 按自身来源定义，不直接继承所有 V4.1 规则。

同一 GEMM 从 FP8 迁移到 FP4，形状不变时 useful MAC/FLOP 不变；变化的是精度归属、原生 K、有效利用率、字节量与可能的质量/转换代价。论文用这条关系解释为什么“低精度峰值更高”不自动等于同倍率的负载加速。
