# 四个研究问题与首版实验协议

研究主线固定为 **prefill 优先、模型精度方案与芯片规格双向搜索**。decode 是分开的对照组，首版不把两者混成任意加权分数。旧 `ratio_dse` 的全部实验继续有效于它们声明的局部边界；新主线使用 LLMCompass 系统存储模型重新评价。

## E1：只改配比是否更差？

固定模型config、输入长度/batch、精度计划、频率、物理DP shape/数量、vector、HBM/L2/SRAM和并行部署，只改变九配比。报告面积是否超预算、是否触发功率限制，以及相对 `1:2:4` 的模拟prefill延时变化。两种问题分列：

- 固定实例数：考察单DP扩展的净运行收益；超面积点只作结构敏感性，不叫预算内最优。
- 固定面积：为更大DP重新配置可安装核心/阵列数，考察机会成本；不得把它与固定实例数混成同一个实验。

验收：精度与useful MAC守恒、输入相同；缺失算子/通信项单列；不能预设低精度比例越高越好。

还需一个单调性对照：若所有资源/工作固定且无面积/功率反馈，新增计算能力保留旧执行路径，最优映射应可选择旧路径，延时不应凭空恶化。出现退化时必须定位到实际改变的供数、调度、padding、功率并发或面积资源，或者识别 mapper 启发式/实现缺陷，不能直接称作新架构发现。

## E2：瓶颈在哪，如何适配？

拆解 tensor服务、vector/Norm/激活/归约、融合量化增量、HBM搬移、L2搬移、已建模的局部供数、launch与通信。通过资源时间线区分忙碌量和真正暴露于关键路径的等待，不能把有重叠的项直接相加当总延时。

局部增加一种资源做敏感性诊断，再搜索合法资源组合。vector加速同步增加ALU/端口成本；带宽增加同步改变合法HBM或L2 bundle。只看算术强度不足以区分吞吐、容量、复用和启动开销瓶颈。

## E3：协同修改后的最佳结果比基线怎样？

固定精度方案，对每个DP配比分别搜索 vector、核心/阵列数量、L2/SRAM容量及HBM/片上带宽配置；在相同总面积和内存容量规则下得到每个配比的最优/非支配候选。若整芯片功率信息不足，保留DP局部功率情景或功率区间，不标成已满足A100 TDP。

必须同时给出相对两个基线的收益：原始规范化A100-derived `1:2:4`；**在相同搜索空间和预算内也经过协同优化的 `1:2:4`**。这样可以区分配比收益与通用调参收益。

## E4：精度迁移后怎样选配比？

沿用 baseline / step1 / step2 / step3 四个累计方案。硬件固定时选迁移与映射，迁移方案固定时选配比与协同规格，分别导出表格。还要比较“原硬件迁移后的收益”与“针对新负载重新设计硬件后的额外收益”。

不加入PPL/准确率阈值。未来情景围绕上下文、batch、专家激活/偏斜及精度分布生成具体计算图；输出说明该情景改变了哪些算子，不能把任意MAC比例混合视为真实模型实现。

## 量化的首版简化

按用户指定，优先将激活量化融合到相邻的Norm算子中：共享输入读取与launch，只增加block归约、scale生成、转换/打包指令与scale字节。不必为这些步骤建立独立kernel，但要在同一个vector资源账本中占用吞吐。

融合必须匹配真实数据依赖。Norm不在相邻producer时，不凭空插入/删除Norm；可选激活或Softmax epilogue融合，或显式转换路径。共享的量化输出只计算一次，MoE的top-k派发不能把相同输入的量化重复计top-k次。KV持久存储重编码和跨设备发送格式另列。在线权重展开与离线权重量化分别处理。

首版将增量按具名操作数/系数计量，提供“无额外量化成本的理想上界”“融合量化”“独立转换”三个对照。系数标为假设/测量/未知，未知不填0；主结论检验在合理增量区间中是否保持。整个prefill可先采用明确的顺序kernel图，仅在tile内部沿用上游有依据的重叠，以控制实现复杂度。

baseline也构造完整量化路径，FP8→FP4比较开销差额，不能重复增加一整套量化。尤其已有W4存储/FP8执行的专家迁移，不会再次减半权重HBM容量；应计量省下的展开与新的激活路径。功率按matrix/vector/访存重叠窗口准入，不能仅检查整次推理平均值。具体参数和已实现接口见 [系统合同](SYSTEM_PARAMETERS.md)。

## 交付顺序

当前先完成可运行的 S1：原始A100 CPU重放、九DP工艺代理与面积替换、vector成本耦合。S1的面积/峰值输出不回答E1–E4的完整模型延时。下一阶段S2替换多精度阵列服务与混合字节布局；S3接DeepSeek prefill和融合Norm量化；S4运行以上四组实验。每阶段保留命令、版本、输入hash与覆盖范围，结果就绪前不预写创新结论。

主图采用**迁移方案×配比的 prefill 延时热图**：四行迁移、九列配比，各单元格显示相对同一基线的延时；分别画固定系统与同预算协同优化两个面板。行内标记最佳配比，列内标记最佳迁移，格内或配套表列出获胜 vector/HBM/存储配置。全部使用同一色标，并将不可行点遮罩，不能把每行各自归一化后再沿列比较。另用关键路径分解图解释热图中的排名改变，用资源消融和量化增量敏感性检验原因。
