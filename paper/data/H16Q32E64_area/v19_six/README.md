# 六种 DP 的七类功能面积与功耗

本批对应 baseline v1.8 电气修复、三个混合顶层与 Q32E64 v1.9，以及未改设计的 E64。
六架构、15 个兼容精度点均采用 N12 TT / 0.7 V / 85°C / 1 GHz、L8 / II=1、ICG 开启；
来自各自通过验收的 DDC 与本轮新采集的 VCS native SAIF。总量验收见
[六架构 PPA](../../../../hw/power/records/v19_six_architectures_20261110.md)。

## 七类边界

| 分类 | 主要归属 |
|---|---|
| 数据解包 | A/B、scale、C 解包模块及解码结果寄存器；保持完整解包模块，不拆其中微小指数或 INT8 取幅值逻辑 |
| 尾数与 scale 乘法 | 元素尾数乘法、乘积重构、scale 系数与幅值乘法、乘积/系数寄存器及 S5 scale/旁路共享幅值寄存器 |
| SOP 累加 | 窄 pair、lane/group 求和、末级 CSA/CPA、累加前符号恢复及相关寄存器 |
| 移位对齐及 delta | 局部/全局移位器、移位差值、group 取幅值、对齐操作数寄存器及 HiF4 局部缩放 |
| 指数处理 | 元素和 scale 指数加法、A_raw、compare_exp、active MAX、共同指数及对应流水寄存器 |
| LZD、规格化与舍入 | group LZD、保留的旧设计 C LZD、最终 FP32 LZD/规格化/舍入/编码及输出寄存器 |
| Others | ICG、控制/特殊值、原始 C 搬运寄存器、跨功能共享且无法可靠拆分的小逻辑 |

同一映射网表的所有模式使用同一物理分类；每个叶单元仅计一次，不能叠加父模块总数。
大模块按层级归属，直接父层内联逻辑按具名信号或寄存器输入锥分离；多功能重叠锥留在 Others。
因此这是可追踪的**功能归集**，并非恢复每个数学运算的独立物理成本。

寄存器的时钟引脚内部功耗计入该寄存器所属功能，ICG 本体列 Others；单元行已有驱动网络
switching，不能再加 net 行或 clock_network 汇总。没有按比例补差或把未分类单元摊入某类。
MXFP4 的乘法类仍含共用寄存器和元素乘法，不能解释成其 scale 尾数乘法正在工作。

## 对架构取舍的启示

1. 基线最大面积类是乘法与 SOP，其次是对齐和解包；不存在“移位器占绝大多数面积”的结论。
   解包类的 2590.286 µm² 中约 903.205 µm² 是寄存器。MXFP4 时该类动态功耗中的寄存器占比很高，
   继续减小解码组合逻辑不一定等比例降低功耗，应先评估字段存储、分类摘要和使能边界。
2. 同 K64 的 MXFP4，baseline 与 E64 的验收总功耗为 11.196534 / 7.036236 mW（1.591 倍）。
   逐单元动态差额为 4.075686 mW，其中寄存器约 62.56%、ICG 约 9.04%、组合逻辑约 28.40%。
   这是同工况物理组成差额，支持优先审查共享宽数据寄存器及其时钟负担；不等于已经证明某个
   未实现的门控方案能消除全部差额。两者功能、寄存位置与数值路径仍有差别。
3. QE 的宽 Q 对齐和共享树仍有成本：Q32E64 的 SOP/对齐分别约占 28.38%/18.80% 面积，
   乘法仅约 14.29%。低精度专用乘法并非唯一热点；后续可对 Q/E 分段寄存、窄 E 保存、
   操作数隔离做独立实验，注意增加选择器后的时序代价。
4. baseline 的 FP32 LZD/规格化/舍入只有约 3.04% 面积；E64 比例升至 8.48%，但绝对面积
   仍约 479 µm²，与 baseline 约 491 µm²接近。相同后端的固定成本占比上升，不代表后端退化。
5. Others 在 baseline MXFP4 中约占 21.79% 动态功耗，却仅占 6.70% 面积，主要含控制/搬运
   寄存器和 ICG 时钟活动。应查看 detail 的物理组成，不能把 Others 全解释为统计遗漏。
6. E64 的窄 pair 寄存器计入 SOP，多精度对应乘积/对齐寄存器分别在乘法/对齐类；因此单看
   SOP 功耗不能断言哪棵树更差。跨架构应结合多类总和、绝对值和 register/combinational 明细。

这里的潜在 RTL 优化尚未实施；本批已实现的改变与时序结果见
[完整设计报告](../../../../hw/power/records/v19_design_report_20261110.md)。

有 matplotlib 的 Python 环境中，从仓库根目录重绘：

```bash
python3.11 paper/data/H16Q32E64_area/plot_area.py --architectures \
  --current-data-dir paper/data/H16Q32E64_area/v19_six \
  --figure-dir paper/figures/v19_six \
  --results-dir paper/data/H16Q32E64_area/v19_six --dpi 180
```

统计入口为 `hw/power/scripts/report_architecture_functions.py`，先对每个验收点 `export`，
再显式指定15个报告目录 `summarize --reports ... --output paper/data/H16Q32E64_area/v19_six`。
不能使用其他网表的分类表或活动文件替代。测量为综合后零延迟、CTS/布线前，不包含布线毛刺和实际时钟树。
