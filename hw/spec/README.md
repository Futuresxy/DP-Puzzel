# 硬件规格职责

先确定数值语义和接口，再设计结构。每个单阵列/单核方案对应独立规格；可从 [module_template.md](module_template.md) 开始。

| 文件 | 职责 |
| --- | --- |
| precision-formats.md | 目标格式清单、来源与需要明确的精度语义 |
| module_template.md | 单模块接口、数值、时序和验证规格模板 |
| 后续各模块规格 | PE/点积、缩放/转换、阵列、局部 buffer、单核接口 |

规格必须区分物理实现、支持的数值模式与运行模式；BF16/FP16、MXFP8/6、MXFP4/NVFP4/HiF4 不能仅以输入位宽代替完整定义。参数、流水、资源共享和 PPA 目标未定案前不生成实现代码。
