# 后续公共驱动职责

当前没有执行脚本，本轮只定义接口。后续实施按下列职责集中到本目录，公共壳入口可放 `scripts/power.sh`；在真实实现与软件检查前不得给出可运行承诺：

| 操作 | 职责 |
| --- | --- |
| check | 只读验证显式源 ID、统一 RTL 门禁、DC 证据、数据、库/模型/工具绑定和计划；不启动工具、不写 PASS |
| prepare | 独占新 run，解析引用、快照策略与模板、写指纹和复现命令；不启动仿真/EDA |
| replay | 已授权时用公共 TB/driver/scoreboard 同源回放 RTL 和 gate，采集指定窗口并验证功能/活动 |
| analyze | 已授权时在匹配库/SDC 上由 PC 读取 gate SAIF，保存原始/注释/有效活动/单位报告 |
| report | 重新验证输入/输出指纹、时序与窗口/活动，生成关联 DC 面积时序的功耗摘要与收敛记录 |
| clean | 先预览，按引用关系仅删除本项目已结束 run 的可再生中间物；不删除源数据或论文证据 |

实现时复用 `scripts/rtl_gate.py` 和 DC 指定 run 的字段，不另造 RTL 验证入口，不把通用实现藏在批次目录或 skill 中。软件回归可用明确标注的临时 fixtures；不得将其当成真实 RTL 结果或 PPA。真实集成验收另行记录。
