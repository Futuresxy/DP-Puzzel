# SAIF / VCD 活动约定

正式输入是冻结 DC 网表上的**门级 SAIF**。优先直接采集；使用 gate VCD 转换时验证转换器、窗口边界/初始值、timescale、duration、TC 和状态驻留。采集方式与附加统计能力逐项记录，不能假定转换 SAIF 保留直接采集的全部状态/路径相关信息。

门级 SAIF 必须来自本次负载、同一网表、单元模型和实际时钟；RTL 的内部波形不能直接给映射网表充当完整门级活动。准确 DUT 层次保存在 window.json，名称变换只接受可追溯的精确映射，不静默剥除任意层级。

未来实现时先验证可手算的时钟、门控、常量、数据、X/Z 和窗口首尾事件；保留 VCD identifier 大小写。对 SAIF 按版本检查驻留总时间和 TC，缺活动与零翻转分开，转换前后的共同统计一致。原始 VCD/SAIF 均放各 run 的 `windows/<segment>/<window>/activity/`，不放在本目录形成共享可变输入。

PC 侧使用本版本 `report_saif` 记录 annotation/missing，另按实际叶单元引脚统计覆盖和关键活动检查；工具分母与独立分母分别保存。进一步以 `report_power_calculation` 或经本版本核验的属性提取审计实际用于计算的关键活动，不把来源标签当作有效值证明。

这里的“功耗相关引脚”指功耗模型使用的可观测逻辑/时钟引脚；电源/地端按供电工况核验，不混入数字切换覆盖率分母。内部不可观测节点、层次别名、时序 notifier 和合法常量各自记录处理方式，不用统一缺失阈值把它们掩盖。

窗口与有效活动验收见 [流程](../flow.md) 和 [窗口策略](../window-policy.md)。本目录当前只有规则，没有采集器、转换器或活动文件。
