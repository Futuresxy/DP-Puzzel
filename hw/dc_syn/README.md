# DC 综合：单阵列 / 单核心面积与时序

必须在当前机器挂载的 EDA 环境内执行。当前会话不能直接运行，因此此处只定义流程，不包含商业工具 runner 或面积/时序结果。

| 后续位置 | 职责 |
| --- | --- |
| scripts/ | DC 驱动、报告提取与质量检查 |
| constraints/ | 经审查的时钟、IO、负载和时序例外 |
| configs/ | 可公开的库/PVT标识；真实机器路径与许可证放本地私有配置 |
| runs/ | 综合 netlist/DDC、报告和日志，默认不提交 |

流程：

1. 选择已通过 RTL testbench 的 export，执行统一指纹/验证门禁。
2. 在挂载 EDA 中确认 DC 版本、工艺库、PVT 和约束；不复制源 RTL。
3. 读取该导出清单，综合单阵列/单核；检查 unresolved references、未约束路径及被忽略的约束。
4. 提取面积、关键路径、WNS/TNS、目标周期与达标状态；报告缺项不得默认为通过。
5. 保存综合 netlist、SDC 和来源信息，供等价性检查及功耗流程。
6. 向 characterization 交付小型记录，大报告通过 URI/hash 归档。

同步复位默认属于时序路径，不能随意 false-path。综合面积与布局布线后面积必须区分；工艺、库、边界或约束不同的结果不能直接当成同一成本模型。

配置字段与状态见 [数据契约](../../docs/data-contracts.md)；未来 DC 专用 skill 统一放根目录 .skill/。
