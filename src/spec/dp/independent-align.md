# 独立对齐：后续探索方案

本页只保留研究边界。当前 CModel 及八级实现合同采用[分组共享方案](shared-align.md)，不把以下方向作为已实现功能。

## 1. 目标

对 T/H 及可能的 Q 路径，探索一次整体指数比较和对齐，减少分级对齐与流水深度。低精度 E 仍按 scale/metadata 粒度组织局部计算。在时序允许时共享乘法、部分移位器和输出通路，但不为共享强制恢复当前分组截断顺序。

## 2. 待定义合同

| 主题 | 后续需要明确 |
| --- | --- |
| 数值 | 各格式对齐范围、scale 顺序、C 参与位置、截断点与保留精度 |
| 结构 | 独立与共享乘法器、移位器、规约树及隔离策略 |
| 流水 | 八级以内的具体阶段、关键路径和固定输出时刻 |
| 接口 | 与当前 datatype、打包、last、C/D 边界的兼容关系 |

## 3. 比较要求

使用相同模式、K、输入、工艺/PVT 和负载，分别报告数学误差、功耗、面积、时序、II 与延迟。不同规约/截断顺序不预设逐位相同；每个方案需要独立明确的位精确参考。当前不启动此方案的 CModel 或 RTL。
