# 组 SOP 规格化与全局对齐：候选比较

状态：用户提出在每个 T2H4Q8E16 输出后检测前导零、获得真实指数，以改善与 C 对齐的精度。本文件记录可审阅的替代方案及推导，**尚未选择新架构**。现行 [出口表](stage-formats.md) 仍以容器 top anchor 对齐；采用不同对齐窗口坐标可能改变截断结果，正式选定时需升架构版本并同步 CModel/RTL 合同。

## 现行坐标正确，但可能浪费保留窗口

令一个有限非零组的幅值 coefficient 为 m、幅值宽 M、小数位 F、无偏参考指数 alpha：

```text
value = (-1)^negative * m * 2^(alpha-F)
A = alpha-F+(M-1)                 // 容器最高位的权重，当前 top anchor
l = clz_M(m)                      // 非零时 0..M-1
e = A-l                           // 实际最高非零位的无偏指数
```

A 已包含 bias 修正和定点整数位的坐标修正，直接以 A 对齐在数值表示上成立；不是“没有先变成 1.x 就无法相加”。问题是强抵消后 l 可能较大，max(A) 高估实际最高位，固定宽度窗口将部分位数浪费在前导零上，更早截断其他较小项。

只修正整数位宽 I-1 无法识别抵消后的任意前导零；也不能只对 raw max-anchor 的赢家做 LZD。比如两个合法非零 token 的 (A,l) 分别为 (20,29)、(10,0)，其真实指数为 -9、10，最大真实指数来自第二个源。

所有候选都只能改善第二次对齐的窗口利用率，不能恢复 S3 已经 RTZ 丢掉的信息，也不能保证跨组强抵消后等同于无限精度点积的一次正确舍入。

## 方案比较

| 方案 | 检测与数据路径 | 精度含义 | 结构代价 / 状态 |
| --- | --- | --- | --- |
| 现行容器 anchor | 无逐组 LZD，按 max(A) 右移 | 坐标正确，窗口可能含大量前导零 | 当前 v1.2 基线 |
| 完整规格化后对齐 | 每源 LZD，m 左移 l，e=A-l；再按 max(e)-e 右移 | 规格化本身无损，充分使用同宽窗口 | LZD、指数修正和前后两段动态移位；用户提出的候选 |
| 精确 LZD＋合并移位 | 每源求 e；保留原始 m，将规格化和对齐合成一次数据移位 | 与上一方案的有限位宽对齐结果完全一致，条件见下文 | 推荐优先评估；保留 LZD，避免单独的规格化左移器 |
| 粗粒度检测＋合并移位 | 每 b 位检测非零块，只消除整块前导零 | 相对精确检测，公共指数最多高估 b-1 位 | 少量检测/编码逻辑，但并非已经证明低功耗；可配额外 guard 比较 |
| 不检测而扩大窗口 | 保留现行 anchor，扩大移位与加法器 | 可用足够额外位覆盖前导零浪费 | 全局移位、树和寄存器一起变宽；不宜未经测量默认采用 |

本表是结构和误差推导，不是 PPA 排名。功能块统计必须计入 LZD、指数修正、方向/mux、移位器和新增寄存位，而不只统计被省掉的左移器。

## 精确 LZD＋合并移位

对 G 个组和一个 C，W 表示全局**无符号幅值**窗口，当前默认 39；每个源的 Mi≤W。有限非零源独立计算 ei=Ai-li，随后用有符号比较选择 E=max(ei)。数学对齐差值 `di=E-ei` 是非负整数。

先规格化再对齐的幅值为：

```text
mi_norm = mi << li                        // Mi 位，只有前导零被移出，精确
yi = (mi_norm << (W-Mi)) >> di             // W 位幅值 RTZ
```

可消去中间规格化数据总线：

```text
zi = mi << (W-Mi)                         // 静态接线补零
ti = di-li = E-Ai                         // 合并位移，可能为负
if ti >= 0: yi = zi >> ti                  // 幅值 RTZ；ti>=W 则为零
else:       yi = zi << (-ti)               // 精确左移，不丢最高有效位
value_aligned_i = (-1)^negative_i * yi * 2^(E-(W-1))
```

负 ti 的绝对值不超过 li，因为 E≥ei；因此左移只消耗 zi 的前导零，不发生幅值溢出。先左移再右移与上述合并形式严格等价，因为被抵消的低位全是结构零；过程中不能截窄有效位，也不能另加舍入。

**di 仍是 unsigned，但 ti 需要方向。** 如果要求移位单元的 shift 端口也为 unsigned，可用 `shift_left` 加 unsigned `shift_amount=abs(ti)`；减法与绝对值先使用足够宽的 signed 临时量。不能把负 ti 直接转成无符号移位量。

S6 单元可采用双向 barrel，或在一套逻辑右移器前后以固定 bit-reverse 接线和方向 mux 实现左移。后者需要额外 mux/路由，不能把它称为零面积/零功耗。此候选改变的是 S6，S3 四个参数化 27-bit T/H/Q 共享右移器保持不变。

Mi、Ai、li、di/ti 和 shift_amount 的含义要分开记录。若 S5 仍输出原始 m，则不能只把原接口 anchor 从 A 改成 e 却不携带 li/原坐标：这样会把数值缩小 2^li。可保留 A 并将 e/l 作为候选控制，或在 S6 用注册的 A/m 计算 e；正式接口随选定流水位置冻结。

## 粗粒度检测的有界折中

从幅值最高位开始按 b 位分块，末块允许较短。检测首个非零块，得到 `c=b*floor(l/b)`；无需精确检测块内前导零。块数由 ceil(M/b) 派生。

```text
e_coarse = A-c
0 <= e_coarse-e < b
E_coarse = max(e_coarse_i)
0 <= E_coarse-max(e_i) <= b-1
```

采用与上节相同的合并移位，把 E 换成 E_coarse，不需真的先左移 c。相对精确 LZD，同宽窗口的公共量化步长最多增大 2^(b-1) 倍；b=4 时最多浪费 3 位。该界限针对对齐网格，不是最终 FP32 ULP 或抵消后相对误差保证。

若在精确方案 W 的基础上增加 b-1 个幅值位，则粗粒度方案的公共 LSB 权重不高于精确方案：`E_coarse-(W+b-2) <= E-(W-1)`。这意味着每项 RTZ 网格至少同样细；不意味着两种结果 bit-exact，也不修复 S3 丢位。b=4 的例子是全局 signed W40→W43，主配置 S7 signed W43→W46；树增长仍由项数推导。

无需 LZD 的纯扩宽也可以构造类似保守保证。默认组 M30 的 l≤29，FP32 C 实际 l≤23；容器 max(A) 相对 max(e) 的高估最多 29。若要覆盖整个保守范围而非依赖负载，可能需额外 29 位窗口。这是避免截断退化的充分界，不是建议配置，也不是精度所需宽度的最紧证明。

## 检测可缩小，但必须保留 scale 后的真实最高位

结构性低零可在 LZD 前从检测输入中省去。例如 NV/HiF4 紧凑 scale 乘积按 W23 形成，补低零后装入组槽；只对合法幅值所在有效片检测、再补回坐标偏移，可以与完整 M30 LZD 等价。实际检测宽度从 signed abs 的安全范围和结构零证明派生，不直接把 W23 或 M30 作为通用常数。

不能仅检测 scale 注入前的 SOP 就忽略 scale 尾数乘法。MX 的单位 scale 系数可旁路，但 NV/HiF4 系数可能改变最高有效位；尤其 NV 的非正规 scale。若提前预测，必须对最终乘积做精确纠正。

FP32 C 的正规非零数已有最高 1，l=0 可旁路；非正规 C 仍须检测或采用同一粗粒度规则。固定 C 出口 M32 中的 8 个低零不改变非零幅值的 clz，检测自然 M24 可等价得到 l。INT8/INT32 路径旁路这些浮点检测和对齐，保留整数精确求和。

## 指数位宽与零/特殊源

bias 去除与指数比较使用 signed；MAX 后的 di 才是 unsigned。所有范围由格式、scale、SOP 宽度、检测最大计数和全局窗口推导：

```text
e_min(mode) = A_min(mode) - l_max(mode)
e_max(mode) <= A_max(mode)
delta_max = max(e_max over sources) - min(e_min over sources)
anchor_bits = swidth(min(e_min), max(e_max))
delta_bits = uwidth(delta_max)
```

默认组 A 范围 [-278,288]、M30，给出精确检测的安全包络 e∈[-307,288]；FP32 C ∈[-149,127] 已被覆盖。故共享 anchor 暂仍可 signed 10 位，di 的保守范围 0..595 需 unsigned 10 位。**两个 signed 10-bit anchor 的差值临时量不能存回 signed 10 位**，默认至少 signed 11 位再检查非负/转 unsigned。S8 非零结果参考下界随窗口重新推导，W39 时安全包络可取 [-345,291]，舍入进位也需覆盖；这些仅是候选范围，不替换当前出口表。

原始无符号指数先零扩展成足够宽的 signed，再扣 bias。scale 指数和、常数修正、减 l、E-A 及最终指数加回 FP32 bias 都检查各自临时范围，禁止只看最终范围而忽略中间溢出。参数变化后重算，不能惯用固定 8-bit 指数或无限扩大到 32-bit。

只有 finite_nonzero 源参与 LZD/MAX。零幅值不按 clz(0)=M 去修正指数，也不让 sentinel 参加减法；全零数值集合使用 safe anchor=0 和独立 numeric_active=false。NaN/Inf 由旁带传播，不能伪装成最大有限指数。最终特殊值 mux 见 [特殊值合同](special-values.md)。

## 八级时序的约束与建议

S5 最终 SOP 依赖两个 lane 的和及适用的 scale 乘法。精确 LZD 必须看到该值，不能把 S4 的某个 lane 前导零数直接当作最终组结果的前导零数。

- 若 S5 完成 abs/LZD/真实指数并注册，S6 只做 MAX、差值和合并移位；S5 的 sum→scale multiply→abs→LZD 可能成为关键路径。
- 若全部检测放在 S6，出现 LZD→指数修正→MAX→差值→移位串联；不能根据功能表宣称达到 1.41 GHz。
- bias 和静态布局修正可在 S3/S4 标量支路预计算；无法提前消除实际抵消或 scale 尾数乘法的数据依赖。C 的 S5 解包/非正规检测是并行支路。
- 可以探索 LZA 与加法并行并做精确纠正，但它不是直接消除最终 scale 乘法依赖的方法，也不是默认低功耗方案。

建议把“精确 LZD＋合并移位”作为下一轮精度候选，b=4 粗粒度版作为有明确误差界的资源对比；当前尚不决定新增周期或采用哪一版。先核对 S5/S6 组合边界与数值效果，保持基线八级目标；实际时序和功耗等待后续实现/EDA。
