# 周期与状态合同

## 1. 固定延迟

默认所有格式使用 L=8，II=1。沿 n 接收请求，S1 于该沿更新，S8 于 n+7 更新；下游在沿 n+8 更新前观察结果。CModel 的 step 返回沿前输出，再推进当前时钟沿。

输入缺失只产生 bubble，已经接收的请求继续推进。NaN/Inf、INT32 溢出及 last 不提前输出，也不改变请求顺序。无输出背压。

## 2. 控制状态

DP 不设置模式会话 FSM。每笔独立保存 datatype、派生控制和 last；valid 逐级推进。上层可按同格式批次发数以降低切换活动，但不构成正确性要求。

全局复位取消全部在途请求并清除有效位。CModel 以 step(reset=true) 表达复位事件；RTL 的具体同步/异步电气实现仍须在接口实施时冻结。无效数据不必逐位清零，但不能被当成有效输出。

## 3. 时序探索

[流水定义](dp/dptop/pipeline.md) 规定八级切分。静态参数 post_scale_norm_extra_stage=1 可增加一级 LZD 计数，使所有格式共同成为 L9；该备用与 L8 数值一致，不是逐请求可变延迟。

目标频率为 1.41 GHz，名义周期约 0.709220 ns。实际组合预算还需扣除寄存、时钟不确定度和约束。CModel 证明不了物理时序；必须检查 S2 乘法/MAX、S5 scale→LZD、S6 MAX→双向移位和 S8 norm/RNE 等路径。
