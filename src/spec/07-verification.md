# 验证合同

状态：验收框架与首批覆盖要求已确定；数值判据、协议细节随 spec 继续完善。当前没有实现或通过结果。

## 三类证据

1. 数学精度：独立参考评价已规定运算相对数学目标的误差；25/35/37 位是设计保留要求，不能直接充当 ULP 阈值。
2. 实现一致性：CModel、Chisel 导出 RTL、手写 Verilog 在定义的有效数据位、特殊值和周期/协议上精确一致；不以误差容限掩盖实现分歧。
3. 硬件约束：结构符合层级/广播/共享要求，DP 延迟≤8；指定工况下 1.41 GHz 时序达标，功耗与面积由真实证据比较。

## v1.1：模块与 profile 验收范围

当前基线必须按 lane→基本组→顶层各自的阶段输出检查，不能把三层延迟相加成多个完整 DP 延迟。当前 H16Q32E64（T8）及 K 变体仍验收 L=8。未来扩展若定义 L=9/10，则按其独立 profile、源列表与 token 同步合同分别验证；不能以未来配置的允许深度替代当前基线约束。

## v1.2：接口、移位结构和数值出口

按 [接口](dp/interface.md) 检查各 datatype 编码/非法元组、仅同格式 A/B、独立 A/B scale 数值和正确广播、C FP32/INT32 切换；结果类型必须跟随原请求。逐级检查 C 的 raw32 延迟与 S5 解包、S1–S8 ctrl/valid/last、r/alpha/A 和 [SxIxFx](dp/stage-formats.md)。有限值与特殊数相邻不得污染控制或摘要。

按 [移位器](dp/shifter-sharing.md) 检查每 lane 四个物理宽移位实例、输入 mux、T/H 的闲置通道隔离、各参数下 W-1/W/W+1 截断；按 [统计合同](dp/resource-accounting.md) 检查功能 ID、实例映射、寄存/mux 归属和报告是否重复计数。当前没有模型/RTL/后端测试结果。

## v1.3：新增规格验证要求

后续三实现须检查 scale **后** LZD，正负 SOP、强抵消/零、NV scale=0/非正规/最高有限、HiF e2差值0/1/2、全部非零单bit幅值和最大幅值。验证合并双向移位与先精确左规格化再右对齐的W位结果完全相同，覆盖正/负/零净移位、抵消计数与巨大d、原anchor/z接口一致性；C最小非正规应得e=-149。zero/special 不参与普通指数MAX。

检查 NV 去 SOP 两个结构零与 HiF 去 scale 两个结构零的整除性、W21裁宽的冗余符号证明及与旧未压缩乘法的精确等价。遍历参数范围后重推乘积/abs/LZD/anchor/delta宽度；检查 delta 在窗口边界及最大保守595、signed临时差值不溢出。

v1.3与v1.2对齐结果不要求bit-exact；v1.3的L8与备用L9则要求数值完全一致，仅周期差一。旧基线≤8验收仍适用于默认profile；本次允许的归一化L9须单独记录profile，不以“八级通过”描述。当前只核对文档公式，不替代未来 CModel/RTL 回归。
