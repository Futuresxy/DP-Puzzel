# 验证方法与验收边界

## 1. 三类独立证据

| 证据 | 判定方式 | 当前状态 |
| --- | --- | --- |
| 架构数值 | CModel 对独立有限窗口参考逐位一致 | 首批 10747 笔通过 |
| 数学精度 | 精确有理数参考、ULP 统计和逐例 RTZ 误差界 | 首批已记录；不等于统一精度目标签核 |
| RTL 与硬件约束 | 两套 RTL 对 CModel 精确一致；时序、面积、功耗实测 | 尚未实施 |

25/35/37 位是保留要求或设计目标，不能直接作为宽松 ULP 阈值。RTL 对 CModel 的有效结果、特殊值和周期必须精确一致。

## 2. 共用数据与参考

全部新版输入位于根 `test/data/dp/`，采用 [DP_INPUTS_V1](../../test/data/README.md)。旧九格式只导入所需 K 的 correct_961，保留来源 SHA256 与五段划分，不继承旧阈值。TF32 K8 和 INT8 K32 使用固定种子新建。

[CModel 合同](dp/cmodel.md)区分整数位精确执行与独立 Fraction 参考。TF32 另记录 FP64 近似；INT8 必须与精确整数乘加及模 2^32 回绕完全一致。保存的 expected 同时包含架构结果和数学结果，未来两条 RTL 读取同一输入。

## 3. 必测覆盖

| 维度 | 必测内容 |
| --- | --- |
| 参数 | K4/K8/K16；局部/全局窗口；非法配置；2/3/5 项树及自然增长 |
| 解包 | 固定 E/M/S 布局、TF32 低 13 位、FP6 低 2 位、scale 广播、HiF4 e1/e2 |
| 算术 | T/H 部分积、INT8 −128、RTZ 负数、窗口边界、scale 极值、bias/F/anchor |
| 共享 scale | 公共 14×8；结构低零整除、14 位幅值上界、22 位乘积与独立符号旁带；覆盖零系数与负组和 |
| 对齐 | scale 后 LZD；z−d 与先左后右等价；正/负/零净移位；大指数差 |
| 特殊值 | qNaN/sNaN、0×Inf、异号 Inf、特殊 C/scale、±0、非正规、RNE 边界 |
| 协议 | 连续 valid、bubble、逐笔换型、FP32/INT32 切换、last、在途复位、非法元组 |
| 周期 | 默认 L8/II=1；备用 L9 单独记录，数值与 L8 一致 |
| 后续阵列 | 广播坐标、64 个输出位置、组间流转、依赖与驻留；尚未覆盖 |

无效数据不比较。后续 RTL 有效数据或必要控制出现 X/Z 应判错。结构检查应确认四个局部共享移位器/lane、公共 scale 乘法器及输入隔离，不能以 CModel 计算相等代替门级共享证明。
