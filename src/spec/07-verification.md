# 验证合同

状态：验收框架与首批覆盖要求已确定；数值判据、协议细节随 spec 继续完善。当前没有实现或通过结果。

## 三类证据

1. 数学精度：独立参考评价已规定运算相对数学目标的误差；25/35/37 位是设计保留要求，不能直接充当 ULP 阈值。
2. 实现一致性：CModel、Chisel 导出 RTL、手写 Verilog 在定义的有效数据位、特殊值和周期/协议上精确一致；不以误差容限掩盖实现分歧。
3. 硬件约束：结构符合层级/广播/共享要求，DP 延迟≤8；指定工况下 1.41 GHz 时序达标，功耗与面积由真实证据比较。

## 覆盖矩阵

| 维度 | 必测内容 |
| --- | --- |
| 配置 | FP16 基准 K4/K8/K16；模式容量关系和非法配置 |
| 格式 | 所有支持模式；HiF8 拒绝；MX 编码子型和 HiF4 细节确认后展开 |
| TF32 | 32 位输入容器、有效位/转换边界，不能退化为 FP32 乘法或缩减容器 |
| 保留精度 | 指定节点宽度/小数点检查、截断及舍入边界、强抵消、大指数差和 scale 边界 |
| INT8 | MXFP8 同并行度；符号极值、精确乘积、规约增长、输出溢出规则 |
| HiF4 共享 | 同一 NVFP4 路径的适用共享资源及约 37 位目标推导，独立格式语义 |
| 周期 | 各模式/K 的 L 与 II；≤8；INT8 短路径与浮点路径的结果冲突 |
| 协议 | 连续有效、气泡、复位、配置生效、排空；支持背压时测试停顿/恢复 |
| DP-Group | 4×4 坐标与广播映射、控制/scale 对齐、结构上无 DP 间脉动依赖 |
| TensorCore | 四组竖直拼接、全 64 个位置、组间控制/数据流与输出；后续补累加 RAW |

定向和固定种子随机测试分别记录。打包/广播映射应有独立检查，避免两个实现使用同一个错误映射后相互通过。无效且未复位的数据值不参与结果比较；有效数据或必需控制的 X/Z 判错。

## 共用环境与范围

根目录 `test/` 共用用例、驱动策略、协议检查、scoreboard 和报告，后端仅做薄适配。一个 K 或一种模式通过不覆盖其他配置；DP 通过不覆盖组/阵列。性能比较使用相同模式、K、负载和工况，INT8 旁路须单独记录延迟及活动。

在输出类型、舍入、保留宽度口径、模式倍率和协议确认前，不生成正式 golden、不声称精度通过。EDA 和 workload 功耗尚未执行。
