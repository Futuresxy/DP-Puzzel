# 系统范围与设计目标

状态：首批要求已确认，详细语义未闭合；本轮仅更新 spec。

## 目标与层级

设计面向多精度张量计算的 TensorCore，层级为 `TensorCore → DP-Group → DP`。TensorCore 是本项目 Cube 计算阵列的具体设计名称，不表示复刻 NVIDIA 的某个物理 Tensor Core 或整颗 GPU。

- TensorCore：16 行×4 列，共 64 个 DP，由四个组竖直拼接。
- DP-Group：4 行×4 列，共 16 个 DP，组内广播，DP 间无脉动传输。
- DP：参数化多精度点积单元，FP16 基准 K 可取 4、8、16。

行/列在本文按物理阵列坐标命名，M/N 映射在 [TensorCore](tensorcore/README.md) 中说明。组间传输与指令形状尚未确定，不能从竖直拼接推断组间脉动。

## 硬约束与优化顺序

| 类别 | 要求 |
| --- | --- |
| 格式 | TF32、FP16、BF16、MXFP8/6/4、NVFP4、HiF4、INT8；HiF8 暂不支持 |
| 输入容器 | TF32 每个元素占 32 位，不能当作完整 FP32 精度乘法 |
| 并行度 | FP16 基准 K∈{4,8,16}；INT8 与 MXFP8 相同 |
| 精度 | 25/35 位保留要求及 HiF4 约 37 位目标，具体口径待确认 |
| 延迟 | DP 从输入到输出不超过 8 级流水；INT8 可评估提前输出 |
| 时序 | 目标 1.41 GHz，必须由指定工艺/PVT/约束下的结果验证 |
| 优化 | 在上述约束满足后，首先降低功耗，其次降低面积 |
| 可探索性 | 集中参数和明确派生公式，无魔鬼数值 |

不以增加到 8 级以上解决时序问题，不以削弱精度、关闭必需格式或隐藏吞吐下降宣称功耗优化成功。实际吞吐需求尚待定义，候选须完整报告 II 与服务时间。

## 交付与当前边界

共用 spec 对应 CModel、Chisel、独立手写 Verilog。`src/` 负责设计；根目录 `test/` 负责共用验证；`hw/rtl/` 负责导出，`hw/dc_syn/`、`hw/power/` 负责后续 EDA。`ratio_dse` 继续负责芯片级组合，不把阵列当作整芯片。

当前不编写三套实现、不运行 EDA。L0、C/D/本地累加器、跨事务依赖、输出类型、吞吐与接口协议仍需逐项定义。旧版 M8N32、原生 K 指令边界和 11/18 级流水均不继承。
