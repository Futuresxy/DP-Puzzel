# 系统范围与设计目标

## 1. 设计对象

本项目设计多精度点积单元，并以此构造计算阵列 Cube。TensorCore 是本项目的阵列名称，不代表复刻某家厂商的物理实现。

| 层级 | 组织 | 责任 |
| --- | --- | --- |
| TensorCore | 16 行×4 列，共 64 个 DP | 四个 DP-Group 竖直拼接 |
| DP-Group | 4×4，共 16 个 DP | 组内广播；DP 之间无脉动依赖 |
| DP | 参数化标量输出点积 | 一笔请求完成 dot+scale+C |

行列与 M/N 的映射、组间传输、L0 驻留和指令调度仍待阵列规范闭合。不能从竖直拼接推断组间脉动。

## 2. 设计约束

| 类别 | 约束 |
| --- | --- |
| 模式 | TF32、FP16、BF16、MXFP8/6/4、NVFP4、HiF4、INT8 |
| 容量 | FP16 基准 K4/K8/K16；T:H:Q:E=1:2:4:8；INT8 同 Q |
| 精度 | T/H/Q 首次对齐保留至少 25 个小数位；FP4 35 位、HiF4 约 37 位整体目标另作误差验收 |
| 延迟与吞吐 | 默认八级，II=1；允许显式 L9 备用，不自动启用 |
| 时序 | 目标 1.41 GHz；需指定工艺、PVT、约束的实测证据 |
| 优化顺序 | 满足功能、精度、吞吐和时序后，功耗第一、面积第二 |
| 参数化 | 位宽、树深和增长量集中定义并派生，不散落人为常数 |

## 3. 实施边界

设计位于 `src/{spec,cmodel,chisel,verilog}`，共同测试位于根 `test/`。生成 RTL 继续进入 `hw/rtl/`，后续综合和功耗进入 `hw/dc_syn/`、`hw/power/`。芯片级组合由 `ratio_dse/` 负责。

当前已实现并验证单 DP CModel 与手写 RTL，并完成 N12 DC 综合。Chisel、Cube 与专用 Q/E/QE 增源尚未实施。历史实现从 Git 查阅。C 的依赖由指令层处理，DP 不持有跨请求 accumulator。
