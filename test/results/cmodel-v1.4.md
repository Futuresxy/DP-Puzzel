# DP CModel v1.4 首批验证

当前 14×8 无符号 scale 的 CModel 和两版 RTL 回归见 [v1.5.1 结果](verilog-v1.4.md)。

记录时间：2026-11-04T22:06:32+08:00。范围：分组共享 DP 的 C++ 模型；没有 RTL 或 EDA 结果。规格正文后续整理为 v1.4.1，数值合同及本批模型源码未改变。

历史基线参数 k_fp16=16、local_shift_mag_width=27、global_signed_align_width=40、L8。先完成九种原格式8649笔，再生成并测试TF32/INT8共2098笔。全量10747笔与独立有限窗口参考逐位一致；以下“数学一致”是另外比较精确点积加C后一次RNE/整数回绕的结果。

FP16的27例、BF16的11例、MXFP8 E5M2的7例及TF32的29例与精确数学结果不同，来自当前有限窗口RTZ/分组顺序，未通过放宽RTL一致性门槛隐藏。所有可比较有限结果满足逐例推导的RTZ误差上界加最终半ULP。特殊输出另作位/类别核对，不将NaN算入有限误差界。没有以这批测试证明任意强抵消下的统一ULP保证，也没有完成FP4 35/HiF4 37位目标的整体精度验收。

INT8全部1045笔精确匹配，含INT32正负回绕与overflow记录。TF32 FP64近似在ID397处与Fraction参考相差1 ULP（极小项影响最终舍入边界），ID1049为math.fsum产生+0与规定−0的差异；两者保留在共享expected中，没有据此修改CModel。

九项定向测试通过，覆盖K4/K8/K16，三组窗口27/40、28/48、32/64，L8/L9，2/3/5叶树，全部小格式元素码与代表格式scale码，IEEE边界/特殊值、乘法重构、15×9共享scale、双向移位等式、连续换型、气泡、reset、非法类型/payload以及整数极值。不是全编码组合穷举。

AddressSanitizer、UndefinedBehaviorSanitizer、LeakSanitizer全量10747笔通过。首次沙箱执行因ptrace与LeakSanitizer不兼容终止；经授权在沙箱外重跑同一命令通过，未关闭泄漏检测。
