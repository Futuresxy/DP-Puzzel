## 数值结果

| E64 精度 | RTL 对保存的 CModel golden 逐位一致 | 对精确数学参考逐位一致 | 最大 ULP |
| --- | ---: | ---: | ---: |
| MXFP4 E2M1 | 961/961 | 961/961 | 0 |
| NVFP4 | 961/961 | 961/961 | 0 |
| HiF4 | 961/961 | 961/961 | 0 |
| 编码、scale、抵消、零符号和 C 边界 | 5288/5288 | 5288/5288 | 0 |

定向数据覆盖全部 16×16 外部 nibble 乘积、HiF4 两侧 e1/e2 的 16 种组合、MX/HiF 的 256 种 scale 编码及 NV 的 128 种非负编码、最大负组和、正负零、组抵消、FP32 非正规/最大有限/Inf/qNaN/sNaN。此覆盖不等于所有 64 元素输入组合的穷举。

六组参数为 (K_FP16,LOCAL_W,GLOBAL_W)：(4,27,40)、(8,27,40)、(16,28,40)、(4,28,48)、(8,32,64)、(16,32,64)。分别覆盖 E16/E32/E64、2/3/5 项后端树。每组 PASS cycles=190、accepted=144、checked=137、cancelled=7；共 822 笔有效输出和 42 笔在途复位取消。取消项不计入数值通过数。

E 内部断点按 E CModel 的 S1 幅值/符号、S2 pair/shift/all_negative、S3 lane12、S4 组幅值/sign、S5 token/C、S6 对齐、S7 总和逐项比较。参数测试匹配 96916 个断点，定向测试匹配 1010008 个断点，总计 1106924。HiF4 使用新的 F/anchor/z 坐标，不能把原多精度 S3/S4 原始比特当作 E 的期望。

原多精度基线另通过 10747 笔固定输入、2922 笔混格式参数输出及 231654 个断点。软件门禁/流程的 33 项测试、CModel 的 16 项测试通过；软件 fixture 不作为 RTL/DC 测量证据。

## 复现与证据

```sh
python3 test/run_verilog.py --frontend e --phase all
python3 test/run_verilog.py --phase all
python3 scripts/rtl_gate.py DP_verilog_e_13931c818a591220
python3 scripts/rtl_gate.py DP_verilog_b9319d81543b5585
```

Verilator 5.030，DUT 按 Verilog-2005 lint；不豁免位宽、锁存器或组合环告警。实际仿真器以 GCC 10.3.1、C++20 coroutine 选项构建，固定随机种子 20271105。CModel 使用固定 Boost 1.83.0 / nlohmann_json 3.11.3；数学参考为独立 Fraction。

完整回归分别位于 test/runs/verilog/上述 run ID/。逐笔数值见 verilator-verilog/<精度>/results.txt（id、FP32 十六进制、类型、last）；verilator-verilog-all-summary.json 位于 run 根目录，simulation.log、cutpoints.txt、lint.log、compile.log 保留在对应子目录。输入输出使用同一 DP_INPUTS_V1，无 DPI、real 运算或硬件查表替代计算。

门禁独立检查两类 top、源清单、源/快照一致性、真实通过日志及完整覆盖，不通过修改 ppa_eligible 绕过。测试只证明所列功能和周期；[N12 DC 面积/时序](../../hw/dc_syn/records/e64_n12_comparison_20261105.md) 单独验收，未执行真实负载功耗、门级等价或布线后签核。
